# 一分钟上报与便捷配对

用户要求将默认 30 秒上报改为 1 分钟、缩短 pairing_id，并在手机复制完整配对信息后自动填写。静止策略仍为 3 分钟，定位时间仍使用原始采集时间。

## 实现约定

- MotionPolicy 与高德初始间隔统一引用 60,000 ms；静止间隔 180,000 ms，首次获取位置无需额外等待一分钟。真实间隔受 SDK、网络与省电影响。
- 新 pairing_id 为 12 位密码学随机字符，字符集 `23456789ABCDEFGHJKLMNPQRSTUVWXYZ`（60 位随机量），避免 0/O、1/I。数据库唯一键防止冲突，冲突重试且不覆盖其他家庭记录。设备令牌、会话令牌与设备 ID 仍使用原生成逻辑。
- 配对 API 继续接受旧标识，不迁移数据库；数字码仍为 8 位，10 分钟过期、5 次输错、单次消费及 IP 限流保持。
- 安卓识别网页现有 JSON 的 server_url、pairing_id、code，验证后整体填写，不触发联网、配对或开启共享。code 必须是字符串且保留前导零；兼容旧 43 位标识。限制输入 4096 字符，只接收文本，拒绝无效地址、缺字段及非法数字码。
- 未配对、无凭证读取错误且未在配对时，窗口获得焦点后尝试读取剪贴板；仅在三个配对字段全空时自动填写，保留设备名称与手工编辑。另提供“粘贴配对信息”按钮主动替换三个字段。无关剪贴板自动忽略；主动粘贴失败显示操作提示。
- 使用 Android 窗口焦点回调满足新系统剪贴板访问约束；不后台监听、不定时读取、不保存或打印剪贴板内容。[Android 官方说明](https://developer.android.com/about/versions/10/privacy/changes#clipboard-data)。不同手机没有共享剪贴板保证，需在待配对安卓手机上复制完整文本。

## 验证与交付

先观察短标识/旧标识配对、60 秒策略、API 25/33 自动填写与主动粘贴测试失败，再实现。覆盖前导零、非法输入不部分覆盖、手工内容保护、不自动启动服务。执行 Go 测试、Android 测试、隔离联调、正式构建和 release lint，沿用签名生成 0.5.4/versionCode 5。真实剪贴板、vivo 锁屏与 Android 13 验收单独记录，不能以 JVM 通过代替。
