# 第四步：iPhone 查看网页

基于已确认的项目上下文和第三步 API，2026-10-15 用户要求继续实现，并确认尚未申请高德 Web JS API Key，先完成页面与配置说明。保留 Go + SQLite、同源 HTTP/IP、网页仅查看不采集位置的方案。没有真实 Key 时不宣称高德实际加载通过。

## 页面和实现选择

采用原生 HTML/CSS/ES modules，Go embed 内嵌静态资源，同一二进制提供 `/` 和 `/assets/`。相比引入框架/单独 Node 服务，当前三个面板的交互规模不需要新增运行时；也不采用服务端每次整页刷新，以便轮询位置和更新地图覆盖物。Node 只用于开发验证。

手机纵向：简洁品牌栏、账号入口、地图、家人列表；宽屏为地图与列表并列。暖白背景、深绿主色、清晰文字和触控目标、安全区适配，不使用虚假地图或编造家人。页面有登录、位置、设备管理三种视图；真实空列表提供添加设备入口。地图不可用时保留精度、电量、定位/同步时间和坐标文字。选择家人突出地图标记，支持查看全部；只绘制最新点及精度圆，不绘制轨迹。

## 认证、管理和状态

复用 auth/me 恢复会话、登录/注销、CSRF。CSRF 和配对信息只留内存，不把凭证、坐标或配对信息存储到 localStorage/sessionStorage/URL。认证失效清除页面数据与地图。注销开始立即移除位置；后端注销失败明确说明会话尚未撤销并可重试，不假称成功。异步请求带代次，注销/撤销/切页后旧响应不能恢复敏感数据。

管理列表显示设备和撤销状态；撤销需页面内明确确认，成功立即移除地图与位置。配对一次性显示 pairing_id 和 8 位数字码、剩余有效期、配对说明；新建明确说明旧信息失效。支持复制可分享的配对 JSON（含当前服务地址），HTTP 下剪贴板不可用时保留可选择文本和手动复制说明；到期、离开管理页、注销均清除。配对并不自动共享；网页没有替手机开启共享按钮。

登录后串行轮询每 10 秒更新位置和设备，手动刷新可用。使用 server_time + 浏览器单调经过时间估算服务端现在，显示原始定位新鲜度与租约。每秒本地重算 stale 和到期隐藏，不等待下一轮请求。请求失败时移除地图坐标并提示未能确认共享状态，不伪装实时；页面隐藏/pagehide 时清除位置与配对信息，恢复可见/pageshow 后重新请求（处理 Safari 后台与 BFCache）。注销/登录切换的旧请求不会覆盖新状态。超时、网络失败、429、403、401 有清楚提示。

## Go 配置和高德

新增可选 `FAMILY_AMAP_JS_KEY` 和 `FAMILY_AMAP_SECURITY_JSCODE`；两者都空时地图禁用，配半组或非法值时启动报错但不输出值。`GET /api/v1/web-config` 需要管理员认证，仅返回 `map:{enabled,key,service_host}` 和时间/轮询参数，安全密钥不下发浏览器。

遵循[高德官方安全密钥说明](https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode)：先设置 window._AMapSecurityConfig.serviceHost，再加载 HTTPS JS API 2.0。Go `/ _AMapService/`（实际无空格，即 `/_AMapService/`）代理只允许已登录管理员的 GET/HEAD，转发至固定高德 HTTPS 目标；样式路径去 webapi.amap.com，其他支持的 API 路径去 restapi.amap.com，覆写配置 key/jscode，不转发 Cookie、Authorization、转发头、客户端主机，不形成任意 URL 代理。上游超时/错误固定响应，不记录带密钥 URL，不转发 Set-Cookie/重定向。只加载地图所需 SDK，不请求浏览器定位。

## 验证与边界

测试先行覆盖：静态路由与 MIME/HEAD/no-store、配置/代理身份与密钥隔离、时间/过期/离线状态逻辑；真实临时后端 + 浏览器覆盖登录、恢复、刷新、配对、撤销、注销、缺地图降级、移动宽度与页面生命周期。地图适配器使用 SDK 替身验证多点/删除/选中/精度圆，明确不等于真实高德瓦片验收。可用 WebKit 时执行浏览器兼容检查；桌面 WebKit/Chromium 不等于 iPhone Safari 真机。

交付可通过 `make run` 打开网页，`make location-demo` 使用隔离数据。所有缓存、截图和临时库留项目内。更新文档与进度，下一步安卓；iPhone 真机、地图真实 Key、公网联调仍须分别记录。
