# 管理页与家庭口令访问设计

日期：2026-11-06。状态：完整设计已获用户批准，本地实现与自动验证已完成；未部署，浏览器启动受环境限制，iPhone/真实地图未验收。需求来源见 [PROJECT_CONTEXT.md](../../PROJECT_CONTEXT.md)，实际交付见 [PROGRESS.md](../../PROGRESS.md)。

## 已确认范围

- 管理入口 `/admin`，家庭入口 `/family?key={标识}`。
- 管理员创建、修改、删除家庭，复制家庭链接；同一设备可以加入多个家庭。
- 管理员切换“所有设备 / 指定家庭”，查看位置与设备信息，沿用现有设备配置、配对、成员加入/移出及撤销功能。
- 未加入家庭的设备仍由原管理员查看和管理。删除家庭不删除设备、不停止上报、不影响其他家庭；最后一个家庭也可以删除，管理员仍可登录并重新创建。
- 家庭页凭独立 7 位数字口令访问，仅展示当前家庭成员位置，不具备管理权限。
- 口令自动生成，也允许管理员手动修改，支持前导零；改口令后旧免输入凭证失效，重新验证后有效 7 天。
- 已撤销设备可以彻底删除，清理所有家庭关联和配置；旧凭证无效，再使用必须重新配对。未撤销设备不允许直接彻底删除。

## 方案选择

推荐独立管理页与家庭页入口、独立家庭查看凭证，共用地图和位置展示模块。后端分别判断管理员与家庭访问权限，前端按入口加载各自功能。页面边界清晰，也便于验证家庭凭证不能调用管理接口。

备选是共用一套页面并根据权限隐藏管理按钮，可以减少模板数量，但管理生命周期、家庭选择与口令流程耦合更重，仍必须实现后端独立鉴权。本轮采用前一种方式，不以隐藏按钮作为权限控制。

设备管理权限从家庭成员关系中独立出来。保留现有设备身份、令牌、共享会话、序号及配置协议，以兼容已安装 Android。

## 管理页行为

- `/admin` 沿用原管理员登录，默认进入“所有设备”；地图与列表使用同一个筛选条件。所有设备指当前管理员有管理权限的设备，不包含其他账号设备。
- 选择指定家庭后，只显示其成员与位置；无家庭成员关系的设备显示在“所有设备”。无位置、共享停止的设备仍可在列表管理，但不伪造地图点；已撤销设备无位置，显示撤销状态与彻底删除入口。
- 所有设备按设备身份去重，即使同一设备加入多个家庭也只显示一个地图点和一条记录。
- 家庭管理支持名称修改、口令修改/重新生成、复制查看链接及删除。家庭标识保持稳定，不提供手工修改标识。仅改名不撤销查看凭证；改口令则撤销。
- 新建家庭默认自动生成口令，也可手工指定严格 7 位 ASCII 数字字符串。生成或修改成功后当次展示口令并支持复制；复制家庭链接只复制 URL，不把口令放入 URL。
- 服务端只保存口令的带盐密码哈希，不提供旧口令回显；忘记时管理员设置新口令。失败时保留用户输入，不把保存失败显示成成功。
- 删除家庭需界面确认，说明设备仍保留。成功后移除成员关系和未消费配对信息，撤销其全部家庭查看授权，切到“所有设备”。删除与后端凭证检查、配对操作使用事务保证一致性。
- 配对继续在指定家庭下生成；“所有设备”视图先选择目标家庭，无家庭时先创建家庭。已有无家庭设备仍可配置、撤销、删除或重新加入家庭。
- “移出家庭”“撤销设备”“彻底删除”分别保留明确文案；彻底删除需要确认，后端只允许处理已撤销设备，返回冲突时刷新状态。

## 家庭页与 7 天访问

- 页面只接受单个非空 `key`；缺失、重复或无效标识不回退到任何其他家庭。不存在或已删除显示链接不可用，不泄漏家庭名称、成员或位置。
- 验证前只展示口令输入。输入使用字符串保留前导零，数字键盘配合长度约束；服务端独立验证严格 7 位数字。
- 验证成功展示家庭名称、成员最新位置、精度、电量、原始定位时间及更新延迟/未共享状态，沿用现有刷新和地图降级行为。不展示配对、成员管理、设备配置或其他家庭列表。
- 免输入期限为每个家庭从验证成功起固定 7×24 小时，不因浏览或轮询延长。换浏览器、清理 Cookie 或过期后需重新验证；同一浏览器可以分别记住多个家庭，各自计时。
- 使用独立 HttpOnly、SameSite Cookie 保存随机浏览器访问凭证；服务端保存摘要和按家庭授权记录，校验家庭存在、口令版本及授权截止时间。不在 localStorage、URL、日志或文档保存口令。TLS 时设置 Secure，沿用当前 HTTP 部署兼容规则。
- 浏览器凭证有效期可覆盖最近授权的家庭期限，但不得延长其他家庭的授权截止时间。服务重启保留未过期授权。
- 修改口令或删除家庭后，旧授权在下一次请求立即拒绝，页面清除对应已显示数据并回到验证/失效状态；轮询周期沿用 10 秒，不宣称远程清除已被访问者保存的内容。
- 家庭退出操作只清除当前家庭授权，不退出管理员或其他家庭。管理员登录也不绕过家庭页口令；管理员直接在 `/admin` 查看位置。
- 验证接口采用同源检查、按 IP 与家庭/IP 组合限流以及有界哈希并发，错误不回显口令。限流持久化，避免重启绕过；不让单个来源永久锁住整个家庭。
- 家庭凭证仅允许读取对应家庭快照和所需地图配置/代理；不得用于管理员查询、设备配置、配对、增删改或设备上传。家庭快照按当前成员关系查询，移出和撤销后不再返回位置。

## 旧数据、权限与迁移

- SQLite 事务升级 schema v4→v5，失败整体回滚；已有账号、设备令牌、配置、共享会话和最新位置保留。
- 新增独立设备管理员关系，依据迁移前的管理家庭授权填充，保留原权限范围；后续设备配对在同一事务建立管理关系。不得根据后来加入的家庭扩大设备管理权限。
- 管理员身份以账号和会话有效性为依据，不再要求默认家庭存在。所有设备查询、配置与撤销使用独立设备管理员关系。
- 由于 `users.family_id`、`devices.family_id` 及 Android 返回字段仍引用历史家庭，删除家庭采用内部删除标记，保留兼容所需历史 ID，不物理级联删除用户或设备。清空对外家庭名称、口令摘要、成员关系、授权和配对信息；公开列表、链接、选择和查询都排除已删除家庭，标识不复用。设备彻底删除仍为物理删除。
- 旧家庭原本没有口令：升级后标记“待设置口令”，管理视图照常可用；管理员首次分享前点击生成或手动设置。未设置前禁止家庭页访问。避免生成无法交付给管理员的未知口令，也不使用公共默认口令。
- CLI 初始化继续兼容现有命令；新建账号的初始家庭同样标记待设置，管理员登录后完成首次分享设置。网页创建的家庭当次生成并展示口令。
- 原 `/` 跳转 `/admin`；原 `/?family=...` 保留选定家庭并跳转管理页，不把旧管理员链接静默变成已授权的家庭链接。新复制链接统一使用 `/family?key=...`。
- 原管理员接口无家庭参数时，默认家庭仍有效则兼容原行为；默认家庭已删除时返回明确不可用，不回退其他家庭。新管理页使用显式家庭或 `scope=owned`，因此无家庭账号也可使用。

## 接口契约与实现边界

继续以 [AUTH_API.md](../../AUTH_API.md)、[LOCATION_API.md](../../LOCATION_API.md)、[DEVICE_CONFIG.md](../../DEVICE_CONFIG.md) 为现有契约，实施时更新已实现的字段和接口，避免将本草案写成已上线能力。

| 接口 | 本轮变化 |
| --- | --- |
| `GET /api/v1/families` | 排除已删除家庭，增加口令是否已设置；不返回口令或摘要 |
| `POST /api/v1/families` | 名称必填，口令可选；缺省生成，成功响应当次返回口令 |
| `PATCH /api/v1/families/{key}` | 修改名称，标识不变；至少包含名称字段 |
| `PUT /api/v1/families/{key}/passcode` | 传口令为手工设置，空对象为自动生成；成功后返回当次口令并使旧家庭授权失效 |
| `DELETE /api/v1/families/{key}` | 按上述规则删除，保留设备管理与上报；跨账号或不存在返回 404 |
| `GET /api/v1/devices?scope=owned` | 基于独立管理关系，包含无家庭设备，保留设备家庭数组 |
| `GET /api/v1/locations?scope=owned` | 新增全部受管理设备位置查询，按设备去重，不与 family 同传 |
| `DELETE /api/v1/devices/{id}` | 保持现有全局撤销语义 |
| `DELETE /api/v1/devices/{id}/purge` | 彻底删除已撤销设备；未撤销返回 409，不存在或无权限返回 404 |
| `POST /api/v1/family/{key}/session` | 输入口令，成功写独立访问 Cookie，返回该家庭授权截止时间 |
| `DELETE /api/v1/family/{key}/session` | 同源校验，退出当前家庭，不影响其他家庭或管理员 |
| `GET /api/v1/family/{key}/snapshot` | 只读家庭会话鉴权，返回家庭名称、精简成员状态和位置快照，不返回管理归属和配置 |
| `GET /api/v1/family/{key}/web-config` | 对应家庭会话鉴权，只提供展示需要的地图配置 |
| `/_AMapService/...` | 在现有管理员授权外支持持有有效家庭授权的访问；固定上游白名单，不转发凭证 |

管理写接口继续要求管理员 Cookie、Origin、CSRF。口令错误、未授权或过期返回固定错误码；未授权不返回快照数据。路径标识与请求参数都不得造成跨家庭访问。列表筛选冲突、重复参数等严格拒绝，不静默回退。

前端分为管理员入口、家庭入口与共享位置展示模块。沿用嵌入资源白名单、地图初始化重试、断网恢复和请求代次检查；切换视图时清除旧点，迟到响应不能恢复其他家庭数据。用户未要求修改设备上报坐标，管理位置指查看位置及沿用设备管理，不新增手工篡改位置入口。

## 验证与交付

1. 迁移：保留旧设备凭证、位置、共享和配置；失败回滚；已有默认家庭删除后仍可登录；无家庭设备可上传、管理及查看位置；无权账号不能访问。
2. 家庭生命周期：创建、改名、手动/随机口令、前导零、未初始化、删除、最后一个家庭删除；删除一个家庭不影响其他家庭和设备管理权限；旧家庭配对信息失效。
3. 访问权限：口令错误和限流、固定七天边界、重启、多家庭独立授权、改口令/删除即时拒绝、家庭会话禁止管理接口、非法 key 不回退。
4. 设备与地图：所有设备去重、指定家庭过滤、无家庭位置、停止/撤销无位置、彻底删除限制与清理、旧令牌不能复用；真实 HTTP 验证只读地图配置/代理授权。
5. 页面：管理登录、两种筛选、家庭 CRUD 与复制、口令进入、过期/撤销清屏、错误/空态、断网重试及迟到响应隔离。自动 DOM 与隔离后端联调，浏览器可用时追加实际渲染检查。
6. 使用项目 Makefile 执行受影响的 `make test vet test-race smoke auth-smoke location-smoke web-smoke`，并构建服务；缓存、测试库和产物均在项目内。Android 未修改则不重复发布 APK，若必须修改则按项目规则递增版本、构建并校验发布包。
7. 同步 API、使用、部署文档及进度，给出 `make run`、`/admin` 和家庭链接的实际使用方式。分别记录自动验证、构建与未完成的 iPhone/真实地图验收，不操作正式数据库或远程部署，不执行 git add/commit。
